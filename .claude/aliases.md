# Claude Code Godot MCP Aliases

## Quick Godot Commands

When working with NeuroVision, you can use these natural language patterns:

### Scene Development
- **"gdscene [scene_name]"** → Create new educational scene with brain visualization setup
- **"gdrun"** → Run NeuroVision project and capture educational workflow output
- **"gdeditor"** → Launch Godot editor for NeuroVision development
- **"gdtest [scene]"** → Test specific educational scene functionality

### Node Management  
- **"add3d [node_type] to [scene]"** → Add 3D educational nodes (brain models, interaction systems)
- **"addui [panel_type] to [scene]"** → Add educational UI components (info panels, controls)
- **"loadbrain [model_name]"** → Load specific brain 3D model with educational context

### Educational Features
- **"makequiz [topic]"** → Create educational assessment scene for brain topic
- **"braininteraction [structure]"** → Set up interactive brain structure selection
- **"educationalpanel [info_type]"** → Create specialized educational information panels

### Performance & Debug
- **"gdperformance"** → Analyze NeuroVision performance for educational requirements
- **"gddebug [issue]"** → Debug specific Godot educational platform issues
- **"gdoptimize"** → Optimize educational scenes for 60fps medical student interactions

## Usage Examples

```
# Quick scene creation
"gdscene hippocampus_exploration"

# Add educational features  
"add3d brain structure selection system to main educational scene"
"addui information panel with medical terminology to brain exploration"

# Test educational workflows
```
