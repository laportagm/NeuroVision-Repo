# Quick Debug & Testing Aliases for NeuroVision

## 🚀 Instant Testing Commands

### Performance Testing
- **"gdfps"** → Check NeuroVision frame rate in educational scenes
- **"gdram"** → Monitor memory usage during brain model loading
- **"gdload"** → Test educational content loading speeds (<3s requirement)
- **"gdrender"** → Analyze 3D brain rendering performance

### Scene Testing  
- **"gdtest [scene]"** → Run specific educational scene validation
- **"gdrun"** → Execute NeuroVision with educational workflow testing
- **"gdstop"** → Stop project and capture debug output
- **"gdvalidate"** → Comprehensive educational platform validation

### Debug Analysis
- **"gddebug [issue]"** → Debug specific Godot educational platform issues
- **"gdlogs"** → Show recent NeuroVision error logs and educational workflow issues
- **"gdstats"** → Display current educational platform performance metrics
- **"gdhealth"** → Quick NeuroVision system health check
