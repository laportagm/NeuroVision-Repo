# HDRI Environment Files

This directory contains HDRI (High Dynamic Range Image) files for educational environment lighting in NeuroVision.

## Available HDRI Files

- `anatomy_room.hdr` - Anatomy classroom with educational lighting (to be added)

## Adding HDRI Files

To add HDRI environment files:

1. Place `.hdr` or `.exr` files in this directory
2. Ensure files are optimized for real-time rendering (2K-4K resolution recommended)
3. Use descriptive names that indicate the environment type

## Medical Lighting Presets

The following HDRI environments are recommended for medical visualization:

- Anatomy classroom environments (neutral, even lighting)
- Laboratory settings (bright, clinical lighting)
- Examination room lighting (focused, directional)

## Performance Considerations

- Keep HDRI file sizes reasonable (<50MB)
- Use lower resolution versions for mobile/web platforms
- Consider baking lighting for static scenes
