# NeuroVis Quick Start Guide

## For Students and Teachers

### Starting the Application

1. **Launch NeuroVis**
   - Double-click the NeuroVis icon on your desktop
   - The main menu will appear with "NeuroVision" title

2. **Begin Exploration**
   - Click "Start Exploration" button
   - The 3D brain model will load automatically

### Basic Controls

#### Mouse Controls
- **Right-Click + Drag**: Rotate the camera around the brain
- **Left-Click**: Select a brain structure
- **Mouse Wheel**: Zoom in/out
- **Shift + Left-Click**: Select multiple structures (if enabled)

#### Keyboard Shortcuts
- **1-8**: Switch to preset camera angles
  - 1 = Front view
  - 2 = Back view
  - 3 = Right side
  - 4 = Left side
  - 5 = Top view
  - 6 = Bottom view
  - 7-8 = Clinical angles
- **L**: Toggle structure labels on/off
- **Q**: Open quiz panel
- **R**: Reset camera to default view
- **Tab**: Cycle through camera presets
- **ESC**: Return to main menu

### Learning Features

#### Structure Information
1. **Select a Structure**: Left-click on any brain part
2. **Read Information**: An info panel appears on the right with:
   - Structure name
   - Description
   - Function
   - Clinical relevance
   - Key facts
3. **Take Quiz**: Click "Take Quiz" button in the info panel

#### Assessment System
1. Press **Q** to open the quiz panel
2. Select an assessment from the list
3. Answer multiple-choice questions
4. View your score and explanations

### Available Brain Structures

1. **Thalamus** - Relay station for sensory information
2. **Hippocampus** - Memory formation center
3. **Striatum** - Movement and reward processing
4. **Ventricles** - Fluid-filled spaces
5. **Corpus Callosum** - Connects brain hemispheres

### Accessibility Features

- **Full Keyboard Navigation**: Use Tab to move between elements
- **High Contrast Mode**: Available in settings
- **Screen Reader Support**: Announces selected structures
- **Adjustable Text Size**: For better readability

### Performance Settings

The application automatically adjusts quality for smooth performance:
- **FPS Display**: Shows current performance (top-left)
- **Quality Levels**: LOW, MEDIUM, HIGH, ULTRA
- Target: Maintains 30+ FPS on all school computers

### Troubleshooting

#### Model Not Loading?
- Wait 5-10 seconds for initial load
- Check that Internal-Structures.glb exists in assets folder

#### Low Performance?
- The app will auto-adjust quality
- Close other applications if needed
- Check FPS counter (should be above 30)

#### Can't Select Structures?
- Make sure you're using LEFT-click
- Try zooming in closer to the structure
- Reset camera with 'R' key

### Educational Tips

1. **Start with Overview**: Use camera preset 1 for front view
2. **Explore Systematically**: Work through structures one by one
3. **Test Knowledge**: Take quiz after exploring each structure
4. **Use Multiple Angles**: Press Tab to see from different views
5. **Focus on Functions**: Pay attention to clinical relevance

### For Teachers

#### Classroom Mode
- Project on screen for group learning
- Use keyboard shortcuts for smooth presentation
- Enable labels (L key) for clarity
- Reset view (R key) between topics

#### Assessment Tracking
- Student progress is saved automatically
- Quiz scores are stored locally
- Review performance in progress tracker

#### Offline Usage
- No internet required for Phase 1
- All content is stored locally
- Perfect for computer labs without internet

### Technical Requirements

- **OS**: Windows 10/11, macOS 10.14+, Ubuntu 20.04+
- **RAM**: 4GB minimum (8GB recommended)
- **Graphics**: Intel UHD 620 or better
- **Storage**: 2GB free space
- **Display**: 1280x720 minimum resolution
