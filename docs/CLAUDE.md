# NeuroVis AI Development Guide

## Quick Reference
- Engine: Godot 4.3 LTS with GDScript
- Architecture: Offline-first, accessibility-first
- No Firebase/cloud features in initial version
- Focus on core educational functionality

## Current Development Phase
Check PROJECT_PROGRESS.md for current status

## Key Principles
1. Every feature must work offline
2. Accessibility is mandatory, not optional
3. Performance must support Intel UHD 620 (30+ FPS)
4. Educational accuracy over technical complexity
